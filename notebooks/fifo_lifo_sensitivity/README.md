# FIFO/LIFO inventory carbon attribution sensitivity

This folder contains the reproducibility material for **Supplementary Information Section S8.5** of the study, *Hourly Carbon Intensity of Sold Hydrogen, Ammonia, and Methanol under Emission-Aware Scheduling*. The notebook applies first-in-first-out (FIFO) and last-in-first-out (LIFO) carbon attribution to the saved **2024 M0 and M2–UpRamp MEF0.5** operating trajectories. It changes the attribution of inventory carbon to withdrawals, not the optimized operating schedules or product sales.

| File or folder | Contents |
|---|---|
| `fifo_lifo_expost_colab.ipynb` | Python/Colab notebook for FIFO/LIFO ex-post CI calculations and validation |
| `inputs/m0.csv` | Saved M0 hourly optimization trajectory |
| `inputs/m2-upramp soft0.5.csv` | Saved M2–UpRamp MEF0.5 hourly optimization trajectory |
| `inputs/grid_mef_upramp_hourly_2024.csv` | Hourly UpRamp MEF emission signal |
| `fifo_lifo_s8_5_results_selected.zip` → `results/tables/` | Annual CI, annual reduction, hourly distribution, and paired-hour comparisons |
| `fifo_lifo_s8_5_results_selected.zip` → `results/per_model/` | Hourly, daily, and annual FIFO/LIFO product-CI ledgers |
| `fifo_lifo_s8_5_results_selected.zip` → `results/audit/` | Selected source-balance, numerical reconciliation, carbon-conservation, and test records |

**To reproduce:** Open the notebook in Google Colab, upload the three input CSVs directly to `/content`, and run the notebook. The analysis requires NumPy and pandas. The selected results archive omits some large intermediate logs; these can be regenerated by running the notebook.

**Cracker-flow data:** The saved input files provide aggregate cracker flows, while label-specific cracker feeds are reconstructed from the hourly labeled ammonia inventory balances. If the original optimization runs provide directly exported label-specific cracker feeds (I forgot to export them in my runs from solver), this reconstruction may be replaced after checking the flow definitions, hourly timing, material balances, and carbon accounting.
